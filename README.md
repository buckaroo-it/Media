## About

This repository holds the logos for the payment methods, card issuers, giftcard brands and identification methods that Buckaroo offers, in PNG and SVG. Every logo is kept up to date here, so linking or downloading from this repository means you get the current version of a brand's artwork.

Buckaroo started as a Payment Service Provider in the Netherlands in 2005, was the first provider to offer iDEAL, and opened a Belgian office in 2020. Today Buckaroo offers over 40 payment methods and giftcards to more than 54,000 organisations.

---

## Using the logos

All images in this repository are free to use for Buckaroo merchants and partners.

Pick the format that fits: **SVG** scales to any size without losing quality and is the better choice for a checkout, while **PNG** is easier to drop into documents and email.

To use a logo, either download it from the table below, or clone the repository:

```bash
git clone https://github.com/buckaroo-it/Media.git
```

> [!NOTE]
> Please host the images yourself rather than hot-linking to this repository. Filenames and paths can change when a brand updates its artwork, which would break a hot-linked image in your checkout.

Guidance on where and how to display payment method logos is in the [payment method logos documentation](https://docs.buckaroo.io/docs/integration-payment-method-logos).
